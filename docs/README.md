# Careers client docs

This repo is the Amal Academy careers client: public board, sign-in, staff hub (org config, Careers tabs, assessment database), reviews, client hiring, `/assessment/[token]`, and `/shared/[id]`. Landings: `staff` → `/staff`, `reviews` → `/reviews`, `client` → `/client`. The API lives in [TR-x-Amal-Careers-API](https://github.com/WhiteboardNewbie/TR-x-Amal-Careers-API).

| Doc | What it is |
| --- | --- |
| [setup.md](setup.md) | How to run this client locally |
| [git.md](git.md) | Branch, commit, and pull request flow |
| [branding.md](branding.md) | Amal identity for the public board and staff banners |
| [mockups/README.md](mockups/README.md) | Screen pictures, grouped by who opens them |

Scope, decisions, and the ERP project tracker setup are in the API log: [project.md](https://github.com/WhiteboardNewbie/TR-x-Amal-Careers-API/blob/main/docs/project.md). Other ERP modules that careers reads, and the open question for each, are in [erp-dependencies.md](https://github.com/WhiteboardNewbie/TR-x-Amal-Careers-API/blob/main/docs/erp-dependencies.md).
